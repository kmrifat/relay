# Testing M9 (ship) by hand

## 1. Onboarding (M9-01)
Start Relay on an empty data folder:

```bash
open -n apps/relay/build/macos/Build/Products/Release/Relay.app --env RELAY_HOME=/tmp/relay-fresh
```

- **Welcome**: your name.
- **Agents**: CLIs found on your PATH, with versions, plus the Demo agent. If Claude Code is there, a reminder to run `claude /login`.
- **Repository**: choose a git folder. It becomes a project named after the folder, with a key.
- **First task**: it is pre-filled, with the agent preselected (Claude Code if present). **Queue it** opens the task as it starts.
- **Team**: **Set up a team** goes to Settings → Team; **Not now** finishes.

**Skip setup** works at any step. Onboarding never shows again once done, or once there is a project.

## 2. Login item and menu bar (M9-02)
- **Settings → This Mac → Start at login.**
  - macOS 13+ asks you to allow "Relay" in System Settings → General → Login Items.
  - After logging out and in, `relay status` answers without opening Relay. relayd started from `Relay.app/Contents/Helpers/relay`.
- **Menu bar:** a checklist icon.
  - The number next to it is what's waiting on you.
  - The menu lists those tasks (clicking one opens it), **Pause new work** (the icon becomes ⏸; running work continues, nothing new starts), **Open Relay** and **Quit Relay**.
- **Closing the window** keeps Relay in the menu bar. Clicking the Dock icon brings the window back. With **Menu bar** off, closing the window quits the app.
- In both cases relayd keeps running, and agents finish their work.

## 3. Icons
Relay has its own icon in the Dock, in Finder, on the iPhone home screen and in notifications. The icon is the blue tile with a checklist, from `design/icon/` (re-render with `tool/render_icon.swift`).

# Testing M10 (Windows + Linux) by hand

CI builds both on every PR. Download them from the run's artifacts:

- `relay-windows-x64`: the app folder and `relay-windows-x64-setup.exe`.
- `relay-linux-x64`: the bundle and `relay-linux-x64.AppImage`.

## Windows 10 (1809+) / 11

1. Run `relay-windows-x64-setup.exe`. It installs for you only, without admin rights, into `%LOCALAPPDATA%\Programs\Relay`. It isn't code-signed yet, so SmartScreen may ask you to confirm.
2. Relay opens and starts relayd from `helpers\relay.exe`. `%APPDATA%\Relay\daemon.json` exists and only your user can read it (`icacls` shows you and SYSTEM).
3. **Agents:** CLIs installed with npm (`claude.cmd`, `codex.cmd`, `gemini.cmd`) are found and show their versions.
   - Runs start through `node.exe` directly, so prompts with quotes, `%`, `&` or newlines arrive intact.
   - **Pause** says it isn't available on Windows yet.
   - **Stop** ends the agent and everything it started (Task Manager shows no left-over `node.exe`).
4. **Terminal** (Code view): PowerShell 7 if installed, else Windows PowerShell. Typing, resizing and Ctrl+C work. Closing the panel ends the shell and anything it started.
5. **Read-only snapshots:** a repo the task doesn't touch is marked read-only (`attrib`), and its files can't be changed. Windows still lets new files be created in its folders.
6. **Shortcuts:** Ctrl+N (new task), Ctrl+K (find), Ctrl+S (save in Code view). "Open in…" offers VS Code, Cursor, Zed or Explorer.
7. **Settings → This computer → Start at login:** adds a "RelayDaemon" entry under Startup apps. After signing out and in, relayd runs: `"%LOCALAPPDATA%\Programs\Relay\helpers\relay.exe" status` answers. A console window may flash briefly at sign-in.
8. Uninstall from Settings → Apps: relayd stops and the startup entry goes. `%APPDATA%\Relay` (your data) stays.

## Linux (x64, GTK 3)

1. Run `chmod +x relay-linux-x64.AppImage && ./relay-linux-x64.AppImage`, or run `relay` from the tarball's `bundle/`.
2. relayd starts as `relay-linux-x64.AppImage --relayd`, so it keeps running after you close the window. Check it with `ps`.
3. Agents installed with npm, pipx, cargo or snap are found, with fish, bash and zsh as login shells alike. Pause and Stop affect the agent's whole process tree.
4. **Terminal:** your `$SHELL`, started as a login shell.
5. **Settings → This computer → Start at login:**
   - writes `~/.config/systemd/user/relayd.service` and enables it;
   - `systemctl --user status relayd` shows it after the next login;
   - in an AppImage, the unit starts the AppImage itself.
6. Notifications appear through the desktop's notification service (`notify-send`).
7. The data folder is `~/.local/share/relay`. The socket is there, or in `$XDG_RUNTIME_DIR` when the path is long.

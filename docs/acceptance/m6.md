# Testing M6 (team sync) by hand

Two Macs work best. With one Mac, a second Relay can run on its own data folder:

```bash
open -n apps/relay/build/macos/Build/Products/Release/Relay.app --env RELAY_HOME=/tmp/relay-teammate
```

Each Relay starts its own relayd. A second Relay app shows the other data folder under **Settings → relayd → Data**.

## 1. Storage (T06)

- **R2:**
  1. In the Cloudflare dashboard, open R2 → **Create bucket** (e.g. `relay`).
  2. Under **Manage API tokens**, create a token with *Object Read & Write* scoped to that bucket.
  3. Note the account ID, access key ID and secret.
- **Or a shared folder:** a folder both Relays can write to (Dropbox, iCloud Drive, a NAS, or `/tmp/relay-shared` for one Mac).

## 2. Create the team

1. Open **Settings → Team** and choose **Create a team**. Name it, pick **Cloudflare R2** (or **Shared folder**) and fill in the fields.
2. Choose **Test connection**. Expected: *Storage works…*. A wrong key or bucket shows the storage's error. An S3 store that ignores `If-None-Match` is reported.
3. Choose **Create team**. The Team box shows the team, storage, *Synced now*, and this Mac under **Devices**. The **Settings** row in the sidebar gets a cloud icon with a green dot.
4. In the bucket, look under `relay/<team>/ops/`. The objects are unreadable bytes, starting with `RLY1`.

## 3. Invite and join

1. Choose **Invite teammate…** → **Copy code**. Send it privately; it carries the storage key.
2. On the second Relay, open **Settings → Team → Join with an invite**, paste the code, and choose **Join team**. Expected:
   - The board shows the first Mac's projects and tasks.
   - Repos show a download icon (no checkout on this Mac yet). Edit a repo to point it at this Mac's checkout. The first Mac's path doesn't change.
   - **Devices** lists both Macs.
3. Paste the same code again on a third data folder. Expected: *This invite was already used or withdrawn.*

## 4. Edit on both

1. Edit the same task on both Macs: different fields, and the same field.
2. Within about 30 seconds (or after **Sync now**), both show every change. Where both edited the same field, the later edit wins.
3. Turn Wi-Fi off on one Mac and edit. The sidebar dot turns orange (*N changes waiting*). Turn Wi-Fi on: the changes go out.

## 5. Teammates' agents (T08)

1. On Mac A, leave **Share my agents** off.
2. On Mac B, press ⌘N. Under **Who**, pick *Claude Code · Rifat* (A's agent) and queue it.
3. On A the task stays queued and is marked *not-shared*. B's agents don't pick it up.
4. On A, turn **Share my agents** on. A starts the run with A's agent. B sees the task running and the run's device.

## 6. Remove a device

1. On A, under **Devices**, choose the remove icon on B and confirm. The key rotates (`relay/<team>/team.json` epoch goes up).
2. On B, the next sync shows *This Mac was removed from the team…* in the Team box, and B stops syncing. B's board stays as it was. New edits on A don't reach B.
3. On B, **Leave team** returns it to the setup screen.
4. Rotate the R2 token afterwards. B still has the old one, which can delete objects but can't read or forge them (format/sync.md §5).
